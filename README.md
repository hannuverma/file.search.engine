# File Search Engine

A high-performance C++ application for searching and indexing files efficiently across your system.

## Features

- **Fast File Indexing**: Quickly index files and directories
- **Efficient Search**: Perform rapid full-text searches across indexed content
- **C++ Performance**: Built with C++ for optimal speed and resource efficiency
- **Scalable**: Handle large file collections with minimal overhead

## Getting Started

### Prerequisites

- C++11 or later
- CMake 3.10 or higher
- Standard C++ libraries

### Building

```bash
git clone https://github.com/hannuverma/file.search.engine.git
cd file.search.engine
mkdir build
cd build
cmake ..
make
```

### Usage

```bash
./file-search-engine [options] [search-term]
```

## Installation

After building, you can install the binary:

```bash
make install
```

## Project Structure

- `src/` - Source code files
- `build/` - Build artifacts (generated)
- `CMakeLists.txt` - CMake configuration
